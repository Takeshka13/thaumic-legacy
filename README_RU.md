# ✨ Thaumic Legacy

*Заново открой забытое искусство тауматургии.*

**Thaumic Legacy** — независимый Minecraft-мод с открытым исходным кодом, вдохновлённый легендарным Thaumcraft.

Наша цель — переосмыслить атмосферу и глубину Thaumcraft 4, 5 и 6 для современного Minecraft, добавив собственные идеи, механики, визуальный стиль и улучшения.

**Minecraft 1.21.1 | Fabric | Java 21**

> ⚠️ **Ранняя стадия разработки**
>
> Thaumic Legacy находится в активной разработке. Мод пока не готов к публичному релизу.

## 🔮 О Thaumic Legacy

Магия — не просто то, что можно создать. Её нужно открыть.

Исследуй окружающий мир, изучай его скрытые свойства, находи магические аспекты, экспериментируй с загадочными веществами и постепенно овладевай забытым искусством тауматургии.

Каждое открытие должно порождать новые вопросы.

У каждого эксперимента должны быть последствия.

И каждый великий тауматург должен понять: за знания приходится платить.

## ✨ Особенности

### 🔍 Исследование мира и открытия

- Сканируй таумометром блоки, предметы, существ и узлы ауры. Записывай наблюдения и открывай магические аспекты.
- Надевай очки откровения, чтобы находить ближайшие узлы ауры и осматривать алхимическое оборудование.

### 🌀 Магические аспекты

- Открой 52 классических первичных и составных аспекта. Свойства материалов и сочетания аспектов лежат в основе исследований и алхимии.

### 📖 Исследования

- Таумономикон делит исследования на восемь категорий. Наблюдения и аспекты вынесены на отдельные вкладки.
- Открытия, предыдущие исследования и эксперименты дают каждому игроку доступ к своим рецептам и методам работы.

### ⚗️ Алхимия

- Готовь алхимические рецепты в тигле, используя растворённые материалы и катализаторы.
- Перегоняй материалы в алхимической печи, устанавливая над ней до четырёх перегонных кубов.
- Переноси эссенцию фиалами или по трубам с клапанами и фильтрами. Храни её в защищённых банках и закрепляй за ними аспекты с помощью этикеток.
- Разлагай составные аспекты на родительские в центрифуге. Автоматизируй изученные алхимические рецепты в тауматории.

### 🌌 Аура и магические последствия

- Измеряй местную ауру, запас вис (Vis) и порчу (Flux). Вис со временем восстанавливается, а порча замедляет восстановление.
- Находи восстанавливающиеся узлы ауры в новых чанках Верхнего мира. Заряжай жезл из их шести запасов первичного вис.

### 🪄 Магический крафт и будущая тауматургия

- Создавай магическое оборудование на магическом верстаке, используя местный вис и открытые исследования.
- Среди ближайших планов — магические изобретения (Magical Artifice), адская печь (Infernal Furnace), алтарь наполнения (Infusion Altar) с магическими пьедесталами (Arcane Pedestals) и рунической матрицей (Runic Matrix), а также големостроение (Golemancy).
- Запланирована переработка графики, моделей и интерфейсов. Заклинания, расширенная генерация мира и более сложные последствия порчи остаются в планах.

## 💻 Сборка из исходного кода

### Требования

- Java Development Kit 21 (JDK 21)
- Git
- Подключение к интернету для загрузки зависимостей Gradle

### Клонирование репозитория

```bash
git clone https://github.com/Takeshka13/thaumic-legacy.git
cd thaumic-legacy
```

### Сборка

Windows:

```powershell
.\gradlew.bat build
```

Linux или macOS:

```bash
./gradlew build
```

Готовый JAR-файл мода будет находиться в папке `build/libs/`.

### Запуск клиента для разработки

Windows:

```powershell
.\gradlew.bat runClient
```

Linux или macOS:

```bash
./gradlew runClient
```

### Запуск сервера для разработки

Windows:

```powershell
.\gradlew.bat runServer
```

Linux или macOS:

```bash
./gradlew runServer
```

Для нормального запуска сервера Minecraft необходимо ознакомиться с пользовательским соглашением EULA и принять его условия.

## 🧩 Поддержка аддонов

Архитектура Thaumic Legacy проектируется с учётом модульности и возможности расширения.

Создание публичного API для независимых аддонов входит в наши долгосрочные планы.
