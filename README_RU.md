# ✨ Thaumic Legacy

*Заново открой забытое искусство тауматургии.*

**Thaumic Legacy** — независимый Minecraft-мод с открытым исходным кодом, вдохновлённый атмосферой и механиками классического Thaumcraft. Проект разрабатывается для **Minecraft 1.21.1**, **Fabric** и **Java 21**.

> **Статус: пре-альфа.** Мод активно разрабатывается и **пока не готов к полноценному прохождению или публичному релизу**.

**Язык:** [English](README.md) · Русский

## О проекте

Магия начинается с любопытства. Изучай окружающий мир, раскрывай скрытые свойства материалов, записывай открытия в исследовательский журнал и постепенно постигай тайны тауматургии.

Основной ориентир — **Thaumcraft 6**, дополненный избранными идеями из **Thaumcraft 4 и 5**. Наша цель — сохранить дух исследований, алхимии и опасных магических экспериментов, но реализовать всё на собственном коде, с оригинальными визуальными ресурсами и новыми игровыми решениями.

## Что уже работает

- **Полевая линза (Field Lens):** изучение отдельных блоков в мире.
- **Исследовательский журнал (Research Journal):** просмотр наблюдений и открытий.
- **Личный прогресс:** открытия хранятся на сервере для каждого игрока и сохраняются после перезапуска.
- **Английская и русская локализации** реализованных механик.

Сейчас доступны наблюдения за **камнем, факелом и дубовым бревном**. Изучение двух разных объектов открывает первую исследовательскую запись.

## Сборка из исходников

**Необходимо:** JDK 21 и Git. Отдельно устанавливать Gradle не требуется — в проекте есть Gradle Wrapper.

```bash
git clone https://github.com/Takeshka13/thaumic-legacy.git
cd thaumic-legacy
```

Windows (PowerShell):

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

Linux/macOS:

```bash
./gradlew build
./gradlew runClient
```

Собранные JAR-файлы находятся в `build/libs/`. Для запуска выделенного сервера разработки используй `runServer` вместо `runClient`. При первом запуске сервера необходимо самостоятельно ознакомиться с Minecraft EULA и принять её.

> Тестовые сборки могут быть нестабильными. Делай резервные копии миров. Значение версии `1.0.0` в текущей конфигурации сборки не означает, что мод уже выпущен.
