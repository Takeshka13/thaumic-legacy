# Feature Matrix

The release reference is Thaumcraft 6.1.BETA26 for Minecraft 1.12.2. Historical notes describe player-facing behavior. Design names, rules, and gates apply to Thaumic Legacy. [Azanor's BETA26 release](https://www.curseforge.com/minecraft/mc-mods/thaumcraft/files/2629023)

**Status.** Locally verified means the implemented scope passed local and manual gameplay checks. Planned means scheduled for later design or implementation. Exploratory means a proposal needs validation before entering the release scope. Deferred means it has no scheduled milestone.

The user confirmed all nine manual Field Observation checks. The local server tests verified isolation using two simulated players. Verification with two real clients on a dedicated server remains open. [QA procedure](FIELD_OBSERVATION_TESTING.md#dedicated-server-with-two-players)

**Effort.** Low means a small bounded feature with limited state. Medium means gameplay and persistence or presentation work. High means several components, significant balance, or multiplayer and performance risks. Very high means a stateful simulation, substantial original content, or an AI system with multiple failure paths. These are relative estimates.

## Historical source notes

- **A. Resource model.** The author describes extracting material energy from objects and drawing ambient power from the world. Public player guides provide additional vocabulary and context. [Thaumcraft project description](https://www.curseforge.com/minecraft/mc-mods/thaumcraft) · [BETA26 player guide overview](https://minecraftguides.net/tc6-sub/index)
- **B. Changes across betas.** Early TC6 author notes cover inventory observations and the effect of pollution on available energy. BETA17 documents a change to crystal behavior. These are evidence of features and revisions, with final tuning left open. [BETA2 notes](https://www.curseforge.com/minecraft/mc-mods/thaumcraft/files/2523647) · [BETA17 notes](https://www.curseforge.com/minecraft/mc-mods/thaumcraft/files/2578520)
- **C. Workshop and tools.** BETA12 names automated alchemy, infusion, construct assembly, focus editing, and rifts. Pipe behavior is described by a player guide whose setup includes optional companion mods. Use the guide only for feature-level observations. [BETA12 notes](https://www.curseforge.com/minecraft/mc-mods/thaumcraft/files/2558310) · [Essentia Tube guide](https://minecraftguides.net/tc6/alchemy/essentia-tubes)
- **D. Research.** Community documentation distinguishes observation from theory and ties both to book-driven progression. Its detailed tables are historical references. [TC6 research](https://ftb.fandom.com/wiki/Research_(Thaumcraft_6)) · [TC6 research guide](https://minecraftguides.net/tc6/getting-started/theories-research)
- **E. Craft and casting.** Player documentation shows a local-energy workbench and modular casting as separate advancement paths. [Thaumometer and workbench guide](https://minecraftguides.net/tc6/getting-started/thaumometer) · [Advanced foci guide](https://minecraftguides.net/tc6/auromancy/advanced-foci-basic-infusion)
- **F. Final release notes.** The BETA26 changelog confirms changes to infusion stability, an advanced construct task, goggles displays, and server-side altar behavior. [BETA26 and hotfix notes](https://www.curseforge.com/minecraft/mc-mods/thaumcraft/files/2629023)
- **G. Exploration.** Player documentation identifies crystal-led onboarding and examples of TC6 flora and fauna. [Crystals guide](https://minecraftguides.net/tc6/getting-started/crystals) · [TC6 feature index](https://ftb.fandom.com/wiki/Module:Navbox/Thaumcraft_6)
- **H. Hazard roles.** Community records describe regional pollution and rifts separately from personal Warp, with examples of remediation. Exact values and edge cases require same-build confirmation. [Flux](https://ftb.fandom.com/wiki/Flux_(Thaumcraft_6)) · [Flux Rift](https://ftb.fandom.com/wiki/Flux_Rift) · [Warp](https://ftb.fandom.com/wiki/Warp_(Thaumcraft_6)) · [Flux cleanup guide](https://minecraftguides.net/tc6/fundamentals/flux-clean-up)
