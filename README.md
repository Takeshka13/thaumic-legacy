# ✨ Thaumic Legacy

*Rediscover the forgotten art of thaumaturgy.*

**Thaumic Legacy** is an independent, open-source Minecraft magic mod inspired by the legendary Thaumcraft experience.

Our goal is to reimagine the atmosphere and depth of Thaumcraft 4, 5, and 6 for modern Minecraft while introducing original ideas, mechanics, visuals, and improvements.

**Minecraft 1.21.1 | Fabric | Java 21**

> ⚠️ **Early Development**
>
> Thaumic Legacy is currently under active development. The mod is not yet ready for a public release.

**🌐 Languages:** English | [Русский](README_RU.md)

---

## 🔮 About Thaumic Legacy

Magic is not simply something you craft. It is something you discover.

Explore the world, investigate its hidden properties, uncover magical aspects, experiment with mysterious substances, and gradually master the forgotten art of thaumaturgy.

Every discovery should lead to new questions.

Every experiment should have consequences.

And every great thaumaturge must learn that knowledge comes at a price.

## ✨ Features

### 🔍 Exploration & Discovery

- Investigate blocks, items, creatures, and magical phenomena.
- Discover the magical aspects hidden within the world.
- Record observations in your personal research journal.
- Unlock knowledge through experimentation.

### 🌀 Magical Aspects

- A comprehensive aspect system inspired by classical Thaumcraft.
- Primal and compound magical aspects.
- Discoverable relationships between materials and magical properties.
- Aspect-driven research, alchemy, and crafting.

### 📖 Research

- A personal research journal.
- Multiple interconnected research branches.
- Discoveries based on exploration and experimentation.
- Meaningful progression through magical disciplines.

### ⚗️ Alchemy

*Planned*

- Extract magical essences from materials.
- Experiment with different ingredients.
- Store and transport magical substances.
- Develop increasingly complex alchemical processes.

### 🌌 Aura & Magical Consequences

*Planned*

- Environmental magical energy.
- Aura manipulation and regeneration.
- Magical pollution and instability.
- Unusual phenomena caused by dangerous experiments.

### 🪄 Advanced Thaumaturgy

*Planned*

- Magical tools and customizable spells.
- Rituals and infusion crafting.
- Multiblock magical structures.
- Magical constructs and golem automation.
- Mysterious locations, creatures, and anomalies.

## 💻 Building from Source

### Requirements

- Java Development Kit 21
- Git
- An internet connection for downloading Gradle dependencies

### Clone the Repository

```bash
git clone https://github.com/Takeshka13/thaumic-legacy.git
cd thaumic-legacy
```

### Build

On Windows:

```powershell
.\gradlew.bat build
```

On Linux or macOS:

```bash
./gradlew build
```

The compiled mod JAR will be available in `build/libs/`.

### Run the Development Client

Windows:

```powershell
.\gradlew.bat runClient
```

Linux or macOS:

```bash
./gradlew runClient
```

### Run the Development Server

Windows:

```powershell
.\gradlew.bat runServer
```

Linux or macOS:

```bash
./gradlew runServer
```

A Minecraft server requires acceptance of its EULA before normal operation.
